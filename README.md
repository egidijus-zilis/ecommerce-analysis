# E-commerce Analysis

Analysis of a synthetic Lithuanian online store dataset (Oct 2025 - Sep 2026)
using Python, SQL and Power BI.

> Note: the dataset was created using Claude and does not depict a real e-commerce shop.

## Dataset

5 related tables in `data/`: customers, products, orders, order_items, user_events.

## Business questions

1. Which acquisition channel has the best conversion rate?
2. How do sales change month to month?
3. Which product categories have the highest return rate?

## Tools

Python (pandas, matplotlib, seaborn), SQL, Power BI

## Project structure

- `data/` - CSV files
- `EDA.py` - exploratory data analysis
- `sql/` - SQL queries
- `powerbi/` - dashboard
